# Budgets, Projects & Forecasting · תקציבים, פרויקטים ותחזית תזרים

## English
The **Planning** module combines account budgets, project profitability tracking, and 13-week cash forecasting.

1. Edit budget figures inline and compare posted actuals with click-through drill-down.
2. Track revenue, supplier bills, and margins across client projects.
3. Run deterministic calculation sandboxes without altering ledger postings.

## עברית
אזור **התכנון והתקציב** משלב ניהול תקציבים לפי חשבון, רווחיות פרויקטים ותחזית תזרים ל-13 שבועות.

1. ערכו סכומי תקציב ישירות במקום והשוו מול ביצוע בפועל עם פירוט תנועות.
2. עקבו אחר הכנסות, הוצאות ושיעור רווח גולמי לכל פרויקט.
3. הריצו כלי סימולציה וחישוב מבלי לשנות את רישומי היומן.
